Decision: Expense edits require the numeric `version` supplied by the editor, so stale requests return 409. `marked_paid` settlements also block leaving until confirmation because they are not yet reflected in balances. No owner-removes-member route exists, so leave eligibility is applied to the available self-leave route.

F12 decisions: all five PostgreSQL settings are required from the environment, with `DB_NAME=settleup_expenses` shown in both examples; there is no runtime database-name fallback. The only PDF in the repository was `SettleUpExpenses_Project_Documentation.pdf`; it was removed as the requested review PDF after the import scan found no code references. The DB-backed test run first exposed an unapplied idempotency migration in the local test database; after applying `npm run migrate`, all tests passed.

E2/E7/E10 decisions: unknown valid emails perform one bcrypt comparison against a process-local dummy hash generated at cost 10, matching the work done for an existing account. The request guard rejects non-object JSON and null bytes recursively. Unicode remains valid in text fields; the emoji regression exercises an invalid email and verifies it returns a clean 4xx.
